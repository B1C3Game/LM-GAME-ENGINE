## Featured Games

### Concept Drift
**A game about transmitting understanding**

- **Players:** 2
- **Time:** 15–20 minutes
- **Difficulty:** Your choice (Easy to Extreme)

One player explains a concept. The other tries to use it. The test is locked before explanation begins. Only a working understanding passes.

**Why play:** Tests real comprehension, not just listening. Hilarious when false transmission is revealed.

## What Makes These Games Work?

Every game here follows the LM-ENGINE spec:

✓ Runs in chat (no app, no server)  
✓ Self-contained prompt (copy and play)  
✓ Determinate scoring (LLM can referee fairly)  
✓ Tested with real players (at least 3 full games)  
✓ Replayable (outcomes vary)
